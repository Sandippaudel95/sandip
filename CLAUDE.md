\# Project: sandipaudel.com.np Redesign



\## Tech Stack

\- Framework: Next.js (App Router)

\- Styling: Tailwind CSS

\- UI Components: shadcn/ui (for minimal, accessible components)

\- Booking Integration: Cal.com or Calendly embed



\## Architecture \& Style

\- Design aesthetic: Academic, professional, and minimalist. Use high contrast, crisp typography, and plenty of whitespace.

\- Tone: Authoritative yet accessible.

\- All pages must be fully responsive (mobile-first approach).



\## Workflow Rules

\- Use functional React components and TypeScript.

\- Before writing code for a new section, read existing components to ensure stylistic consistency.

\- Keep the bundle size small; do not introduce heavy libraries unless explicitly requested.
