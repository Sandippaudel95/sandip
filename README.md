# Sandip Paudel: personal academic website

Static site hosted on GitHub Pages at https://sandipaudel.com.np

- `index.html`: main page
- `booking.html`: research consultation booking
- `booking-status.html`: private booking status page linked from client emails
- `admin.html`: private booking management (sign-in required)

Paid, per-hour consultation booking with QR payment, using Supabase (database, file storage, server function) and Resend (email).
See **SETUP.md** for the one-time setup steps.
